# Diccionario Oficial de MEF

## Objetivo

El Diccionario Oficial de MEF constituye la referencia única para el vocabulario utilizado en todo el Framework.

Su propósito es garantizar que los mismos términos tengan el mismo significado en:

- Fundación
- Arquitectura
- ADR
- RFC
- Código fuente
- Comentarios
- Documentación
- Guías
- SDK

El diccionario establece el lenguaje oficial del proyecto.

---

## Alcance

Este documento no sustituye la documentación técnica.

Cada término resume un concepto y referencia el documento donde fue definido oficialmente.

---

## Organización

Cada término contiene:

- Identificador
- Nombre
- Definición
- Categoría
- Documento de origen
- Responsabilidad
- Relación con otros componentes
- Ejemplos
- Conceptos relacionados
- Conceptos que no deben confundirse

---

## Convenciones

Los términos deberán:

- tener una única definición oficial;
- evitar sinónimos ambiguos;
- mantenerse consistentes en todo el proyecto;
- actualizarse cuando exista un ADR que modifique su significado.
