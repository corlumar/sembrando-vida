# Diccionario Canónico MEF — V2

## 1. Propósito

DICCIONARIO V2 constituye el proceso de reconstrucción del vocabulario
canónico de Modular Enterprise Framework (MEF).

Su construcción se realizará a partir de las autoridades documentales
vigentes del proyecto y no mediante la reproducción automática del
Diccionario V1.

---

## 2. Principio de reconstrucción

El Diccionario V2 deberá derivarse del corpus normativo real de MEF:

- Fundación (`FND`);
- Arquitectura (`ARQ`);
- Ingeniería (`ENG`).

El Diccionario V1 podrá utilizarse exclusivamente como:

- evidencia histórica;
- fuente de términos candidatos;
- mecanismo de comparación;
- instrumento para detectar pérdida conceptual;
- referencia para construir la migración V1 → V2.

Una definición del Diccionario V1 no será considerada correcta únicamente
por existir previamente.

---
