# S1.3.9.3 — Saneamiento de Dependencias Frontend y AdminLTE

## 1. Objetivo

Eliminar AdminLTE y los estilos específicos asociados a layouts, dashboards y sidebars heredados que ya habían sido retirados de la baseline.

## 2. Estado

**Estado: CERRADO / VALIDADO**

Rama: `refactor/saneamiento-repositorio`

## 3. Hallazgo inicial

`resources/js/app.js` todavía importaba:

```javascript
import 'admin-lte/dist/css/adminlte.min.css';
import 'admin-lte/dist/js/adminlte.min.js';
```

`package.json` todavía incluía `admin-lte`.

`resources/css/app.css` conservaba reglas específicas para:

```text
app-sidebar
sidebar-brand
sidebar-menu
small-box
small-box-icon
app-footer
```

Estos componentes ya no existían.

## 4. Clasificación

Se definió:

```text
REMOVE
├── admin-lte
├── imports AdminLTE
├── estilos de sidebar
├── estilos small-box
├── estilos app-footer
└── personalizaciones ligadas al dashboard anterior
```

Se decidió conservar temporalmente:

```text
Bootstrap
Bootstrap Icons
Tailwind CSS
Alpine.js
```

porque todavía existen referencias legítimas que se analizarán en S1.3.9.4.

## 5. Eliminación de AdminLTE

Se ejecutó:

```powershell
npm uninstall admin-lte
```

Esto actualizó `package.json` y `package-lock.json`.

## 6. Limpieza de app.js

Se eliminaron los imports CSS y JS de AdminLTE.

## 7. Limpieza de app.css

Se retiraron reglas heredadas asociadas a sidebar, small-box, app-content, card y app-footer.

El CSS quedó reducido a la baseline Tailwind y estructura mínima general.

## 8. Validación de residuos

Se ejecutó:

```powershell
Get-ChildItem .\resources,.\app -Recurse -File |
Select-String -Pattern 'admin-lte|AdminLTE|app-sidebar|sidebar-brand|sidebar-menu|small-box|small-box-icon|app-footer' |
Select-Object Path, LineNumber, Line
```

Resultado:

```text
0 coincidencias
```

## 9. Validación npm

`npm list --depth=0` confirmó que AdminLTE ya no está instalado.

`package.json` también dejó de contener `admin-lte`.
