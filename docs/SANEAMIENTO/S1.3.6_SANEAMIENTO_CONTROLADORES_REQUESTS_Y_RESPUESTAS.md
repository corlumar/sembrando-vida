## 5. Decisiones principales

### AdminDashboardController

**ELIMINADO**

Dependía de entidades y tablas retiradas del dominio anterior.

### UserController

**ELIMINADO**

Mantenía dependencias con la estructura geográfica y administrativa
anterior.

### DashboardController

**ELIMINADO**

No tenía consumidor real en las rutas actuales y constituía código
muerto.

### StoreUserRequest

**ELIMINADO**

Validaba campos retirados de la nueva baseline.

### LoginResponse

**ELIMINADO**

Implementaba redirecciones basadas en roles heredados.

### ProfileController

**CONSERVADO**

Su funcionalidad es genérica y compatible con la nueva arquitectura.

### ProfileUpdateRequest

**CONSERVADO**

Trabaja únicamente con datos genéricos de perfil.

### LoginRequest

**CONSERVADO**

Mantiene autenticación por correo y contraseña y protección mediante
rate limiting.

------------------------------------------------------------------------

## 6. Autorregistro público

Se decidió que el autorregistro no formará parte de la baseline saneada.

`RegisteredUserController` permitía crear usuarios únicamente con:

``` text
name
email
password
```

pero la nueva arquitectura requiere que la creación y autorización de
usuarios sea una decisión controlada.

Por ello se retiraron:

``` text
RegisteredUserController.php
register.blade.php
GET register
POST register
```

## 11. Incidencia final detectada

Durante la limpieza del enlace residual de registro en:

``` text
resources/views/welcome.blade.php
```

Git reportó:

``` text
D resources/views/welcome.blade.php
```

La intención de esta subfase **no es eliminar la vista completa**, sino
retirar únicamente el bloque relacionado con:

``` blade
@if (Route::has('register'))
    ...
@endif
```

Por tanto, antes del cierre definitivo se debe:

1.  restaurar `welcome.blade.php`;
2.  eliminar únicamente el bloque de enlace a `register`;
3.  confirmar que Git registre el archivo como modificado (`M`) y no
    eliminado (`D`);
4.  comprobar que no queden referencias al autorregistro.

------------------------------------------------------------------------
