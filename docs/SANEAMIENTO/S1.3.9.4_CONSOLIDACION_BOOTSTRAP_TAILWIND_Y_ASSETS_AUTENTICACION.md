# S1.3.9.4 — Consolidación de Bootstrap, Tailwind y Assets de Autenticación

## 1. Objetivo

Consolidar la capa frontend de la aplicación sobre una baseline única y coherente, eliminando dependencias duplicadas o innecesarias y normalizando los assets de autenticación.

Esta subfase forma parte de **S1 — Saneamiento del repositorio**.

---

## 2. Estado

**Estado: CERRADO / VALIDADO**

Rama de trabajo:

`refactor/saneamiento-repositorio`

Versión Laravel observada durante la validación:

`13.20.0`

---

## 3. Situación inicial

Después de retirar AdminLTE en S1.3.9.3, todavía coexistían:

```text
Tailwind CSS
Alpine.js
Bootstrap 5 por npm/Vite
Bootstrap 4.6.2 por CDN en login
Bootstrap Icons
Font Awesome
Popper
jQuery por CDN
CSS inline específico de login
```

Esto generaba una baseline frontend duplicada y poco coherente.

---

## 4. Hallazgos

La auditoría confirmó que:

- las vistas de Breeze de recuperación, confirmación y verificación ya utilizaban Tailwind;
- `login.blade.php` era la principal vista que todavía dependía de Bootstrap;
- Bootstrap Icons no tenía consumidores detectados;
- Font Awesome no tenía consumidores detectados;
- Popper no tenía consumidores directos detectados;
- Bootstrap se cargaba simultáneamente desde npm y CDN;
- jQuery solo aparecía asociado al Bootstrap heredado del login.

---

## 5. Decisión arquitectónica

Se estableció como frontend canónico:

```text
Tailwind CSS
Alpine.js
Axios
Vite
```

Se decidió retirar:

```text
Bootstrap
Bootstrap Icons
Font Awesome
Popper
jQuery CDN
Bootstrap CDN
```

También se decidió reconstruir `auth/login.blade.php` con Tailwind.

---

## 6. Normalización de resources/js/app.js

`resources/js/app.js` quedó reducido a:

```javascript
import './bootstrap';

import Alpine from 'alpinejs';

window.Alpine = Alpine;

Alpine.start();
```

La línea:

```javascript
import './bootstrap';
```

se conserva porque corresponde al archivo JavaScript de inicialización de Laravel y no al framework Bootstrap.

## 10. Validación de residuos

Se ejecutó:

```powershell
Get-ChildItem .\resources -Recurse -File |
Select-String -Pattern 'bootstrap|Bootstrap|jquery|jQuery|cdn.jsdelivr|cdnjs.cloudflare|btn-|form-control|form-group|form-check|d-flex|alert-' |
Select-Object Path, LineNumber, Line
```

Resultado:

```text
resources/js/app.js: import './bootstrap';
```

Esta coincidencia es válida y corresponde al bootstrap JavaScript de Laravel.

No quedaron referencias al framework Bootstrap, jQuery o CDNs heredados.
