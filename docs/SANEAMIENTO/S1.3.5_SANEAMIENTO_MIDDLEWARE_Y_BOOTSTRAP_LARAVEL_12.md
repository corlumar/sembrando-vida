# S1.3.5 --- Saneamiento de Middleware y Bootstrap Laravel 12

## 1. Objetivo

Sanear la configuración HTTP heredada, eliminando middleware sin uso
real y consolidando `bootstrap/app.php` como punto de configuración del
esquema moderno de Laravel.

> **Nota de entorno:** la subfase conserva la denominación histórica
> "Laravel 12", pero `php artisan about` reportó **Laravel 13.20.0**
> durante la validación.

## 2. Estado

**Estado: CERRADO / VALIDADO**

Rama de trabajo: `refactor/saneamiento-repositorio`

## 3. Estado inicial

Coexistían `app/Http/Kernel.php` y `bootstrap/app.php`. El Kernel
heredado registraba el alias:

``` php
'role' => \App\Http\Middleware\RoleMiddleware::class,
```

mientras `bootstrap/app.php` ya utilizaba `withMiddleware()`.

## 4. Hallazgos

Se revisaron `Kernel.php`, `RoleMiddleware.php`, `bootstrap/app.php` y
los usos de `role:` y `middleware.*role`.

No se encontraron rutas activas utilizando `RoleMiddleware`. Sus únicas
referencias funcionales estaban en el propio Kernel y en la clase del
middleware.

La coincidencia en `User.php`:

``` php
return $this->belongsTo(Role::class);
```

corresponde únicamente a la relación Eloquent.

Además, `RoleMiddleware` utilizaba:

``` php
Auth::user()->role->name
```

lo cual podía fallar cuando `role_id` fuera `null`.

## 5. Decisión arquitectónica

Se decidió:

-   eliminar `app/Http/Middleware/RoleMiddleware.php`;
-   eliminar el Kernel HTTP heredado;
-   no registrar el alias `role` en `bootstrap/app.php`;
-   conservar `bootstrap/app.php` como punto vigente de configuración;
-   no introducir autorización por roles hasta existir un requerimiento
    real.

## 6. Archivos eliminados

``` text
app/Http/Middleware/RoleMiddleware.php
app/Http/Kernel.php
```

Git mostró la segunda eliminación con la capitalización existente en el
repositorio como `app/Http/kernel.php`.

## 7. Bootstrap

`bootstrap/app.php` se conservó sin necesidad de aliases personalizados.
Continúa centralizando routing, commands, middleware y exceptions.

## 8. Validación de referencias

Después de las eliminaciones se buscaron:

``` text
RoleMiddleware
middleware.*role
role:
```

No quedaron referencias funcionales al middleware. La única coincidencia
fue la relación `belongsTo(Role::class)` de `User.php`.
