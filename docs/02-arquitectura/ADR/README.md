# Architecture Decision Records (ADR)

## ¿Qué es un ADR?

Un Architecture Decision Record (ADR) documenta una decisión arquitectónica importante del ERP Core.

Cada ADR explica:

- el problema identificado;
- las alternativas evaluadas;
- la decisión adoptada;
- las razones que la justifican;
- las consecuencias técnicas y organizacionales.

Los ADR forman parte de la documentación oficial del proyecto y deberán mantenerse versionados junto con el código fuente.

## Estado

Cada ADR tendrá uno de los siguientes estados:

- Propuesto
- Aprobado
- Reemplazado
- Obsoleto
