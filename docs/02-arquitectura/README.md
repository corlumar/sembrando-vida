# Arquitectura del ERP Core

La sección de Arquitectura contiene los documentos que definen la estructura, los principios, las decisiones y los lineamientos técnicos que gobiernan el ERP Core.

Su propósito es mantener una visión común del sistema y proporcionar una referencia para el diseño, desarrollo, seguridad, despliegue y evolución de la plataforma.

## Gobierno de la arquitectura

Toda decisión que afecte de forma relevante la estructura, tecnologías, integración, seguridad o evolución del ERP Core deberá:

1. analizarse técnicamente;
2. documentarse;
3. evaluarse mediante criterios de calidad;
4. registrarse mediante un ADR cuando corresponda;
5. mantenerse versionada en Git.
