# Diccionario Oficial de MEF

## Objetivo

El Diccionario Oficial de MEF define el significado único y oficial de los términos utilizados en la arquitectura del Framework.

Su finalidad es garantizar que todos los desarrolladores, arquitectos y colaboradores utilicen el mismo lenguaje.

El diccionario complementa los documentos de Fundación y Arquitectura.

No sustituye la documentación técnica.

Cada definición hace referencia al documento donde el concepto fue introducido formalmente.

---

## Principios

Cada término deberá:

- tener una única definición oficial;
- evitar ambigüedades;
- utilizar el mismo significado en toda la documentación;
- indicar su documento de origen;
- incluir ejemplos cuando sea necesario.

---

## Organización

Las entradas se agrupan alfabéticamente.

Cada definición incluye:

- Definición.
- Categoría.
- Documento de origen.
- Componentes relacionados.
- Ejemplos.
- Conceptos relacionados.
- Conceptos que no deben confundirse.
