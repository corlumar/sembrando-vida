# MEF

## Modular ERP Framework

---

# ¿Qué es MEF?

MEF (Modular ERP Framework) es un Framework para el desarrollo de aplicaciones empresariales basado en Laravel.

Su propósito es proporcionar una plataforma modular sobre la cual puedan construirse diferentes soluciones empresariales mediante componentes reutilizables.

MEF no es una aplicación.

MEF es la infraestructura que permite crear aplicaciones.

---

# Nuestra filosofía

Desarrollar una vez.

Reutilizar siempre.

---

# Nuestro propósito

Reducir la complejidad del desarrollo de software empresarial mediante una arquitectura modular, desacoplada y mantenible.

---

# Nuestro alcance

MEF proporciona:

- Infraestructura
- Arquitectura
- CLI
- Registro de módulos
- Descubrimiento automático
- Sistema de plantillas
- Builders
- Eventos
- Seguridad
- Plataforma

Los módulos proporcionan:

- CRM
- RH
- Compras
- Inventarios
- Producción
- Finanzas
- Sembrando Vida
- Cualquier solución empresarial

# Nuestra meta

Convertir a MEF en un Framework empresarial moderno para el ecosistema Laravel.
