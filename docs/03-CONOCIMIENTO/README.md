# 03 — Conocimiento

## Objetivo

Esta sección define cómo se organiza, clasifica, relaciona y evoluciona el conocimiento dentro de MEF.

No describe componentes del Framework.

Describe el propio conocimiento del proyecto.

El objetivo es que cualquier documento, clase, módulo o decisión tenga una ubicación clara dentro de un modelo común.

## Principios

Todo conocimiento debe:

• tener una ubicación única.

• pertenecer a una categoría.

• tener un responsable.

• tener una trazabilidad.

• evolucionar de forma controlada.

• poder localizarse fácilmente.
